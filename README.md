# FragRank

Учебная клиентская часть портала рейтинга игроков Counter-Strike 2. Этап 1: общая структура сайта и главная страница.

## Запуск

1. Откройте папку `FragRank` в Visual Studio Code.
2. Установите расширение **Live Server**, если оно ещё не установлено.
3. Нажмите правой кнопкой мыши на `index.html` и выберите **Open with Live Server**.
4. Проверьте переходы по меню. Для проверки мобильного вида уменьшите окно браузера до ширины менее 800 px или включите режим устройства в инструментах разработчика.

Установка npm-пакетов и сборка не нужны. Открывайте сайт через HTTP-сервер: ES-модули на главной странице могут блокироваться браузером при запуске через `file://`.

## Структура

```text
FragRank/
├── index.html       # Главная: приветствие, топ-3, сводка, описание
├── ranking.html     # Контейнер будущего рейтинга
├── player.html      # Контейнер будущего профиля
├── compare.html     # Контейнер будущего сравнения
├── stats.html       # Контейнер будущей статистики
├── about.html       # Контейнер будущего описания проекта
├── css/
│   └── styles.css   # Общие стили, компоненты, адаптивность
├── js/
│   ├── main.js      # Мобильное меню на всех страницах
│   ├── demo-data.js # Вымышленные игроки и демонстрационные суммы
│   └── home.js      # Отображение данных главной страницы
├── favicon.svg     # Локальный значок сайта
└── README.md
```

Все HTML-страницы содержат общую шапку и подвал. Текущий раздел задан атрибутом `aria-current="page"` у ссылки основного меню. При изменении общих ссылок обновляйте их во всех шести файлах.

## Данные и границы этапа

Игроки, команды и показатели вымышлены; это явно указано в интерфейсе. Три карточки берут данные из `js/demo-data.js`. Сводка описывает отдельный вымышленный набор из 128 игроков, 24 команд и 384 матчей и не вычисляется по длине массива трёх игроков. Рейтинг является условной демонстрационной оценкой, а не официальной методикой.

Разделы рейтинга, профиля, сравнения, статистики и информации о проекте пока содержат заголовки и подготовленные контейнеры. Таблицы, фильтры, выбор игроков и расчёт статистики появятся на следующих этапах.

Мобильное меню открывается кнопкой «Меню», закрывается повторным нажатием, клавишей Escape, переходом по ссылке или кликом вне шапки. Без JavaScript ссылки меню остаются видны; для топ-3 предусмотрено текстовое представление.

## GitHub Pages

Загрузите файлы с сохранением структуры в репозиторий. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, нужную ветку и папку **/(root)**, затем сохраните. Все ссылки и пути относительные, поэтому сайт подходит и для адреса репозитория вида `username.github.io/FragRank/`. Серверная часть, база данных, внешние шрифты и библиотеки не используются.
